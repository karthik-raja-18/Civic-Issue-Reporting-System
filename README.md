# 🏙️ CivicPulse — Civic Issue Reporting System

CivicPulse is a modern, full-stack, crowdsourced civic issue reporting and resolution platform. It empowers citizens to report public issues (e.g., potholes, broken streetlights, water leaks), track their progress, and upvote community reports, while providing municipality admins with tools to prioritize, categorize, and resolve issues efficiently.

The system incorporates **Generative AI** for auto-classification, duplicate detection, and a RAG (Retrieval-Augmented Generation) assistant, alongside a **WhatsApp bot** for streamlined mobile reporting.

---

## 🏗️ Architecture & Component Map

The project is structured as a monorepo consisting of the following core directories:

*   **[`civic-frontend`](./civic-frontend)**: A React-based Single Page Application (SPA) built using Vite, styled with Tailwind CSS, and containing real-time map dashboards.
*   **[`civic-issue-backend`](./civic-issue-backend)**: A production-ready Spring Boot REST API that handles auth, issue management, analytics, notification dispatches, and third-party API integrations.
*   **[`docker-compose.yml`](./docker-compose.yml)**: The multi-container runtime configuration that orchestrates the Frontend, Backend, and MySQL database with pre-configured development parameters.
*   **[`migration.sql`](./migration.sql)**: Database schema expansions, indexes, and custom tables (such as upvotes, WhatsApp sessions, AI classification feedback, and RAG chat logs).

## 🌟 Core Features

### 1. Citizen Interface
*   **Interactive Dashboard**: View all reported issues on a map or list, with dynamic filtering by status, category, and zone.
*   **Create Issue**: Report an issue with coordinates, title, description, category, and an image upload (integrated with **Cloudinary**).
*   **Social & Community**: Upvote existing issues to increase priority score and leave comments to provide updates.
*   **Smart Alerts**: View local status change notifications in-app or receive them via SMS (**Twilio**).

### 2. Administrator Dashboard
*   **Interactive Management Hub**: Review pending issues, update statuses (`PENDING`, `IN_PROGRESS`, `RESOLVED`, `CLOSED`), upload resolution proof photos, and delete inappropriate content.
*   **Category Overrides**: Correct AI-assigned categories. Every correction logs to `category_feedback` to form a labeled dataset for future model fine-tuning.
*   **Performance Metrics**: Track resolution times and performance markers categorized by geographic zones.

### 3. 🤖 AI-Driven Core (The Smart Engine)
*   **Category Auto-Classification**: Uses Gemini to analyze free-form descriptions and predict the most appropriate category with confidence score metrics.
*   **Hybrid Duplicate Prevention**: When a user submits an issue, the system validates duplicates using:
    *   *Geographic Gate*: Matches open issues within a **200m radius**.
    *   *Semantic Embedding Similarity*: Computes cosine similarity of description embeddings (generated by `gemini-embedding-001`). Matches with $\ge 85\%$ similarity are flagged as duplicates.
*   **RAG AI Assistant**: A chatbot that retrieves context-relevant local issues using text embeddings and uses Gemini to answer citizen inquiries (e.g., *"Are there any water outages resolved near main street?"*).

### 4. 💬 WhatsApp Reporting Bot
*   **Conversation-Driven Flow**: Citizens can report issues on WhatsApp by providing coordinates/location pins, describing the problem, and sending photos.
*   **State Machine Engine**: Driven by backend state tracking (`whatsapp_sessions` table) to compile data progressively.

## 🚀 Getting Started

### Method A: Run via Docker Compose (Recommended)

Docker Compose sets up the Frontend, Backend, and MySQL database automatically, complete with hot-reloading for development.

1.  **Prerequisites**: Ensure you have [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.
2.  **Spin up the containers**:
    ```bash
    docker compose up --build
    ```
3.  **Access the applications**:
    *   **Frontend**: http://localhost:3000
    *   **Backend API**: http://localhost:8080
    *   **MySQL Database**: http://localhost:3306

---

### Method B: Manual Local Setup

#### 1. Setup the Database
1.  Launch your local MySQL server.
2.  Create the database:
    ```sql
    CREATE DATABASE civic_db;
    ```
3.  Run the DDL scripts in [`migration.sql`](./migration.sql) to add custom tables, indexes, and embedding schemas.

#### 2. Run the Backend API
1.  Navigate to the backend directory:
    ```bash
    cd civic-issue-backend
    ```
2.  Configure database credentials in [`src/main/resources/application.properties`](./civic-issue-backend/src/main/resources/application.properties):
    ```properties
    spring.datasource.username=YOUR_MYSQL_USERNAME
    spring.datasource.password=YOUR_MYSQL_PASSWORD
    gemini.api.key=YOUR_GEMINI_API_KEY
    ```
3.  Build and run the project:
    ```bash
    mvn clean install
    mvn spring-boot:run
    ```

#### 3. Run the React Frontend
1.  Navigate to the frontend directory:
    ```bash
    cd civic-frontend
    ```
2.  Install required NPM dependencies:
    ```bash
    npm install
    ```
3.  Launch the development server:
    ```bash
    npm run dev
    ```
4.  Open the application at http://localhost:3000. Vite will proxy API requests (e.g. `/api/*`) directly to the backend running at `localhost:8080`.

## ⚙️ Key Environment Variables

Define the following environment variables (already configured in [`docker-compose.yml`](./docker-compose.yml)) to activate integrations:

| Environment Variable | Description |
| :--- | :--- |
| `GOOGLE_API_KEY` | Your Google Gemini developer API key (used for embeddings, classification, and RAG chatbot). |
| `JWT_SECRET` | 64-character hex string for signing JWT authentication tokens. |
| `CLOUDINARY_CLOUD_NAME` | Cloudinary account cloud name identifier (for storing issue photos). |
| `CLOUDINARY_API_KEY` | Cloudinary API Key. |
| `CLOUDINARY_API_SECRET` | Cloudinary API Secret credentials. |
| `TWILIO_ACCOUNT_SID` | Twilio SID credentials (for SMS/WhatsApp notifications). |
| `TWILIO_AUTH_TOKEN` | Twilio authorization token. |
